FinSage

Multi-agent AI financial research platform

Generates a 15–20 page equity research report for any U.S. public company, grounded in SEC filings and live market data, using data pipelines, RAG, and multi-LLM consensus.

  • < 7 minper report
  • 28 filingsin the RAG index
  • 0citation errors in testing

My part: Team of three. I owned the full AWS layer (Terraform infrastructure, the Bedrock retrieval layer, and Guardrails) and the Airflow ingestion pipeline into Snowflake, end to end.

Live demo Code
  • Built the AWS retrieval layer: a Bedrock Knowledge Base over 28 SEC filings, with Titan Embeddings V2 indexed into OpenSearch Serverless. Fixed cross-company citation errors by checking each chunk's ticker against its S3 path, with no citation errors across test reports after the fix.
  • Owned the Airflow ingestion pipeline end to end: five sources into a three-layer Snowflake warehouse (raw, staging, analytics) using idempotent MERGE loads, dbt models with schema tests, and a 0–100 data quality score that flags stale feeds and schema drift.
  • Four-agent pipeline (chart, validation, analysis, report) builds 8 vision-validated charts and assembles the finished PDF in under 7 minutes.
  • Bedrock Guardrails block investment advice and redact PII, and a custom Python multi-LLM consensus layer (Claude, Llama 3, Mistral) flags disagreements before a report is delivered.
  • All AWS infrastructure provisioned with Terraform: S3 versioning and lifecycle tiering, KMS encryption, and Secrets Manager with no hardcoded credentials.

AWS cloud infrastructure platform

Multi-account deployment with Terraform

A FastAPI and PostgreSQL web app deployed across two AWS accounts, built entirely as code, with automated testing, zero-downtime releases, and monitoring with alarms.

  • 29 testson every push
  • < 5 minrolling deploys
  • 9 metricswith alarms
Web app Terraform Serverless
  • Terraform across two AWS accounts: a VPC with public and private subnets, RDS in a private subnet, a load balancer with SSL/TLS through ACM, and Auto Scaling from 3 to 5 instances with health-gate promotion.
  • GitHub Actions runs 29 integration tests on every push before any instance is replaced, then rolls out zero-downtime updates in under 5 minutes using Packer images and launch template versioning.
  • CloudWatch with structured logging and 9 custom StatsD metrics and alarms for API latency, database query time, and S3 throughput in one dashboard.
  • KMS key rotation, Secrets Manager injected at runtime, least-privilege IAM roles per service, and security groups restricting traffic between services, with no credentials in code or config.
  • Serverless email verification on SNS, Lambda, SES, and DynamoDB, designed to be idempotent so retries never send twice.

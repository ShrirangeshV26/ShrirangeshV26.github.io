FinSage

AI-powered financial research platform

Generates a 15–20 page equity research report for any U.S. public company in about 7 minutes, using financial data pipelines, RAG, and multi-LLM consensus.

My part: Team of three. I owned the AWS infrastructure and the Bedrock RAG and Guardrails, and worked on the Snowflake warehouse, data ingestion, and Airflow DAG.

Live demo Code
  • Pulls prices, news, 10-K filings, and fundamentals from five sources into a three-layer Snowflake warehouse built with dbt and scheduled daily in Airflow.
  • Four-agent pipeline (chart, validation, analysis, report) generates 8 charts, refines each through a 3-round AI vision critique, and assembles a branded PDF.
  • SEC filing RAG on an AWS Bedrock Knowledge Base (Titan embeddings, OpenSearch Serverless), with guardrails that block investment advice and redact PII.
  • Next.js and React frontend on a FastAPI backend, with a dashboard, analytics explorer, SEC filing analysis, and a chatbot.

AWS cloud infrastructure

Multi-account deployment with Terraform

A production-style web app deployed across two AWS accounts, built entirely as code, with automated testing, zero-downtime releases, and full monitoring.

Web app Terraform Serverless
  • FastAPI and PostgreSQL app across two AWS accounts, provisioned with Terraform: VPC networking, a load balancer, Auto Scaling from 3 to 5 instances, and SSL/TLS.
  • GitHub Actions runs 29 automated tests, builds machine images with Packer, and rolls out zero-downtime updates in under 5 minutes.
  • CloudWatch monitoring with structured logging and 9 custom StatsD metrics for API response time, database latency, and S3 performance.
  • KMS encryption with 90-day key rotation, Secrets Manager with no hardcoded credentials, and serverless email verification on Lambda, SNS, SES, and DynamoDB.
